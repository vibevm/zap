## Implemented behavior

CLI entrypoints: zap.map.overview.v1, zap.map.object.v1 and zap.map.route.v1.
They read an explicitly selected strategy revision. Existing identities,
structural kinds, work purposes, record state, acceptance meaning and typed
relationships remain separate. Nonmaterialized work and omitted information
stay explicit. Landmark facets do not create new completion authority.

criteria, source/evidence references, relationship coverage and assessment
freshness. Valid long Unicode Fact descriptions are preserved. Reverse index
links are checked against current record predicates; forward and reverse
Fact/Region meanings agree. Contract read and write subjects remain distinct.
Blockers are explicitly NotEvaluated by this descriptive projection.

The optional map.work-assessment-proposed DataProposal persists descriptions
and independent effort/time/complexity/difficulty/uncertainty data for existing
Work. Cards expose its current Work/selected-contract source fingerprint before
the first assessment. Exact record CAS, command retry, source staleness,
nonblank text, range consistency, contextual grade requirements and bounded
existing evidence references are enforced. Unassessed can retain partial
explanations. This record changes no Work, contract, approval or dispatch state.

Route projections validate selected membership and prerequisite closure,
preserve unique shared work and compute a topological precedence lower bound.
Missing/stale estimates are excluded from current aggregates; known subtotals
are not a complete estimate or a resource-feasible calendar schedule.

## Deliberate boundaries

This is the agreed initial projection over existing strategy/work, not a new
canonical milestone-acceptance subsystem or graphical client. A resource card
is reference-only where no richer record exists; it does not invent capacity,
availability or reverse membership. Extra descriptive ratings are supplied
data, not observed capability or acceptance, and do not automatically choose
models or execution routes. Source-plan decoding cost is explicit and separate
from bounded output/index components. These limitations are documented in the
public strategic-map guide and contract.

No NEXT activation, live campaign migration, local inference, legacy Python
acceptance, old-cache deletion or 1.0.0 mutation occurred. No implementation
work remains in SM01–SM05. Registry publication and a future graphical client
are separate follow-up actions, not silently performed by this implementation.
