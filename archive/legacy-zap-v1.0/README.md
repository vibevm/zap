# Historical Zap 1.0 source

`source/` preserves the previously published `org.vibevm.world/zap@1.0.0`
package exactly as extracted from repository history. It is retained for
archaeology, compatibility investigation, and truthful interpretation of its
historical receipts.

This directory is outside `vibevm/vibepacks`, is not a registry package, and is
not the current Zap release. Current source is `org.vibevm.zap/{zap,lens}` at
mutable version 1.0.0. Do not rewrite the historical proof files to make them
claim evidence for the current release.
